## 一句话结论

> **A5 说"H3 变面积所以密度有偏差"，这件事本身是对的；
> 但偏差既然等于"面积比"，除以真实面积就消失了，跟用哪个网格无关。
> 归一化之后，H3 与 A5 的差别不到 1%——比"网格摆放位置"带来的噪声还小。**

换句话说：**行业在争一个三阶问题，而一阶问题在别处。**

| 因素 | 典型影响 | 量级 |
|---|---|---|
| 归一化（分母用错） | 经纬 1° 可达 **114×**；强度量全球平均 **−9.3%** | 一阶 |
| 分辨率 / 选区 | 格子缩小 64× → 读数涨 **7.5×** | 一阶 |
| 划区效应（边界位置） | CV **0.3%–0.8%** | 二阶 |
| 网格几何（等面积与否） | 归一化后 **< 1%** | 三阶 |

## 三个可以证明的命题

**命题 1（偏差恒等式）**　未归一化报告的相对误差，逐格恒等于面积比：

$$\frac{\tilde\rho_i}{\rho_i}=\frac{A_i}{\bar A}$$

**命题 2（判决条件）**　两个单元发生排名反转，当且仅当面积比超过真值比的倒数：

$$\alpha > 1/\beta$$

**命题 3（强度量）**　面积不等本身不产生偏差，面积**与所测之量相关**才产生。
经纬格的"格平均"等价于按 $1/\cos\varphi$ 加权，所以偏差 9.3%；H3 的面积变化与纬度无关，偏差 0.07%。

| 编号 | 问题 | 结论 |

| **E1** | 未归一化的误差到底等于什么？ | 斜率 1.00（9 个网格）；经纬 1° 的误差有 **91.5%** 由面积解释，H3 r6 只有 17.1%，A5 是 0.000 |
| **E2** | A5 的 Airbnb 排名结论成立吗？ | 补上"每 km²"这一臂后排名**一位不变**；差异来自格子大小（$R^2=0.78$，斜率 −0.67） |

## 新方法：旋转蒙特卡洛

DGGS 没法像经纬格那样平移，所以划区效应（MAUP zoning）一直无法量化。
本仓库提出用**球面旋转**构造划区集合——旋转是保测变换，把点集整体旋转等于把同一套网格换一个摆放位置。

```python
M = random_rotation(rng)                  # 均匀随机 SO(3)
for r in range(R):
    lon, lat = xyz_to_lonlat(lonlat_to_xyz(lon, lat) @ M.T)
    theta = hotspot(grid, lon, lat)       # 重新分箱
```

$\{\theta_r\}$ 的离散度就是划区效应的非参数置信区间。
